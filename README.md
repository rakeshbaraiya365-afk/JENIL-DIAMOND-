# JENIL DIAMOND

Gujarati-first diamond karigar work, payment and SMS management app.

## Included
- JENIL DIAMOND branding/logo
- Worker name + mobile number
- Date-wise diamond work entries
- Quantity, rate and automatic total
- Payment entries and remaining balance
- Worker-wise history and totals
- Month/date summaries
- SMS composer with worker work summary
- Contact number 9998929262 in SMS
- Local offline storage
- Codemagic Android APK/AAB workflow

## Build
1. Open this project in Flutter/Android Studio.
2. Run `flutter pub get`.
3. Run `flutter run` for testing.
4. For Codemagic, connect the repository and use `codemagic.yaml`.
5. Add an Android signing key in Codemagic with the reference `jenil_diamond_keystore`.

Package/application id is intended to be `com.jenildiamond.app`.
